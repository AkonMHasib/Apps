## 🏷️ Versioning & File Naming

Application builds should follow a consistent naming convention:

`AppName-vX.Y.Z.apk`

Examples:

- `SUBTools-v1.0.0.apk`
- `SUBTools-v1.1.0.apk`
- `SUBTools-v1.1.1.apk`

For future applications, replace `AppName` with the relevant application name.

Where practical, versions follow semantic versioning:

- **Major:** Significant changes or incompatible updates.
- **Minor:** New features and improvements.
- **Patch:** Bug fixes and minor updates.

## 🔐 Security & Compatibility
